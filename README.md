## How to use

1. Open a series, then a post folder (e.g. `EP01 ...`).
2. Each post folder holds the **video** (`.mp4`), the **cover** (`cover.jpg`, when one was made), slide images for slideshows, and a ready-to-paste **`caption.txt`**.
3. To download a file: click it, then click the **Download** button (top right of the file view).
4. Some posts have no cover or caption yet; write your own for those.
